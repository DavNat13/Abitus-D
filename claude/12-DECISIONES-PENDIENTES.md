# 12 - Decisiones pendientes

Lo que está aquí NO se asume. Si una tarea depende de una decisión abierta, se usa el valor provisional indicado, se marca en el código o documento como PENDIENTE y se pregunta al usuario. Cuando se cierre una decisión, se mueve a `02-MEMORIA.md` o `02b-MEMORIA-DECISIONES-2.md`.

Las decisiones de la ronda del 2026-11-22 (nombre, applicationId, hosting, correo, edad, unidades, respaldos, tareas programadas) están cerradas en `02b-MEMORIA-DECISIONES-2.md`.

## Cómo cerrar una decisión

1. El usuario responde en el chat.
2. Claude Code actualiza este archivo (elimina la fila) y la agrega a la memoria con fecha y motivo.
3. Ajusta los documentos afectados y el código marcado como PENDIENTE.
